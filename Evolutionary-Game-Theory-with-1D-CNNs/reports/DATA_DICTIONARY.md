# Research Data Dictionary & Variable Specifications

**Project:** Forecast-Aware Evolutionary Game Theory for Renewable Energy Communities  
**Scope:** Raw, Processed, Model Window, and Game Simulation Variables  
**Date:** November 1, 2026  

---

## 1. Raw Dataset Columns (Kaggle Solar Power Generation & Weather)

### Generation Data (`Plant_1_Generation_Data.csv`, `Plant_2_Generation_Data.csv`)
| Column Name | Data Type | Sampling Rate | Physical Units | Description & Harmonization Rule |
| :--- | :--- | :--- | :--- | :--- |
| `DATE_TIME` | String (Timestamp) | 15 minutes | Local Time (IST) | Plant 1 format: `%d-%m-%Y %H:%M`; Plant 2 format: `%Y-%m-%d %H:%M:%S`. |
| `PLANT_ID` | Integer | - | Categorical ID | Unique identifier for solar farm (Plant 1: `4135001`, Plant 2: `4136001`). |
| `SOURCE_KEY` | String | - | Inverter ID | Alphanumeric identifier for string inverter (22 inverters per plant). |
| `DC_POWER` | Float | 15 minutes | kW (Harmonized) | **Plant 1:** Raw values in 10-Watt units (scaled by $0.10$ during ingestion to obtain true kW). **Plant 2:** Raw values in true kW ($1.0\times$). |
| `AC_POWER` | Float | 15 minutes | kW | Inverter AC power output. Aggregated across all 22 inverters per timestamp. Peak capacity: Plant 1 = $29,150.21\text{ kW}$, Plant 2 = $25,979.76\text{ kW}$. |
| `DAILY_YIELD` | Float | 15 minutes | kWh | Cumulative daily AC energy generated by inverter (resets at midnight). |
| `TOTAL_YIELD` | Float | 15 minutes | kWh | Lifetime cumulative AC energy generated by inverter. |

### Weather Sensor Data (`Plant_1_Weather_Sensor_Data.csv`, `Plant_2_Weather_Sensor_Data.csv`)
| Column Name | Data Type | Sampling Rate | Physical Units | Description |
| :--- | :--- | :--- | :--- | :--- |
| `DATE_TIME` | String (Timestamp) | 15 minutes | Local Time (IST) | Timestamp matching generation series. |
| `PLANT_ID` | Integer | - | Categorical ID | Unique identifier for solar farm. |
| `SOURCE_KEY` | String | - | Sensor Station ID | Weather sensor module identifier. |
| `AMBIENT_TEMPERATURE` | Float | 15 minutes | $^\circ\text{C}$ | Ambient outdoor air temperature ($20.0^\circ\text{C}$ to $40.0^\circ\text{C}$). |
| `MODULE_TEMPERATURE` | Float | 15 minutes | $^\circ\text{C}$ | Photovoltaic panel back-surface temperature ($20.0^\circ\text{C}$ to $65.0^\circ\text{C}$). |
| `IRRADIATION` | Float | 15 minutes | $\text{kW/m}^2$ | Solar global plane-of-array irradiance ($0.0$ to $1.25\text{ kW/m}^2$). |

## 2. Engineered Time & Cyclical Features
| Feature | Range | Formula | Purpose |
| :--- | :--- | :--- | :--- |
| `sin_tod`, `cos_tod` | $[-1.0, 1.0]$ | $\sin(2\pi \cdot \text{hour}/24)$, $\cos(2\pi \cdot \text{hour}/24)$ | Encodes continuous diurnal diurnal solar periodicity without 23:45 to 00:00 discontinuity. |
| `sin_dow`, `cos_dow` | $[-1.0, 1.0]$ | $\sin(2\pi \cdot \text{day}/7)$, $\cos(2\pi \cdot \text{day}/7)$ | Encodes weekly cyclical patterns for residential demand. |

## 3. Microgrid & Evolutionary Game Variables
| Variable | Symbol | Default Value | Units | Economic / Physical Definition |
| :--- | :--- | :--- | :--- | :--- |
| Number of Prosumers | $N_p$ | 50 | - | Active prosumers with rooftop PV and BESS. |
| Number of Consumers | $N_c$ | 50 | - | Pure energy consumers purchasing power. |
| Retail Import Tariff | $p_{\text{grid}}$ | 0.28 | $\$/\text{kWh}$ | Price paid to utility grid for imported energy. |
| Feed-in Tariff | $p_{\text{fit}}$ | 0.07 | $\$/\text{kWh}$ | Price received from utility grid for exported energy. |
| P2P Mid-Market Price | $p_{\text{p2p}}$ | 0.175 | $\$/\text{kWh}$ | Bilateral trading price within renewable community. |
| Transaction Cost | $c_{\text{tx}}$ | 0.01 | $\$/\text{kWh}$ | Community network maintenance transaction fee. |
| Imbalance Penalty Ratio | $\beta$ | 0.50 | - | Penalty surcharge on shortfall ($p_{\text{imb}} = (1+\beta)p_{\text{grid}} = \$0.42/\text{kWh}$). |
| Risk Penalty Multiplier | $\lambda_s$ | 2.50 | - | Prosumer risk aversion coefficient against forecast standard deviation $\sigma_t$. |
| Cooperation Proportion | $x(t)$ | $[0.0, 1.0]$ | - | Population fraction adopting P2P energy-sharing strategy. |
| Defection Proportion | $1 - x(t)$ | $[0.0, 1.0]$ | - | Population fraction adopting selfish storage/export strategy. |
